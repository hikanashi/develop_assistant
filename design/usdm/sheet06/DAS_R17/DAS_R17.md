# 【DAS_R17】SYS/SWEプロセス実行環境分離

## 要求

SYSプロセスはブラウザ上のWebアプリで、SWEプロセスは開発者PC上のツールで実行する

### 理由

SWEプロセスはSimulinkやCANoeなど専用ツールが必要であり、実行環境の特性に応じた最適な手段を提供するため

### 説明

記載無し
