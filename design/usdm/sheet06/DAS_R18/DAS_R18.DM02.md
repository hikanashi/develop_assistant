# 【DAS_R18.DM02】マネージドサービス採用基準

## 要求

開発効率、スケーラビリティ、不具合リスク、運用コスト等を比較し、有利な場合はクラウド事業者固有のマネージドサービスを利用する

### 理由

OSS利用による開発・運用コストの増大を避け、合理的な技術選定を行うため

### 説明

記載無し
