# 【DAS_R22.DM01】チャット質問への回答生成

## 要求

レポートに関するチャットでの質問に対し、成果物の内容をもとに回答を生成する

### 理由

ユーザーがレポートの根拠となる成果物情報を踏まえた正確な回答を得られるようにするため

### 説明

記載無し
