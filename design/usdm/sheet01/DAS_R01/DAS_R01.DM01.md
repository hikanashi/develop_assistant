# 【DAS_R01.DM01】顧客情報の登録・変更・削除

## 要求

顧客情報を登録・変更・削除する

### 理由

顧客ごとの製品・開発プロセスの管理を可能にするため

### 説明

記載無し

## 仕様

| 種別 | 内容 | 仕様番号 |
| --- | --- | --- |
| 仕様 | 顧客情報を新規登録する | 【DAS_R01.DM01-01】 |
| 仕様 | 登録済みの顧客情報を変更する | 【DAS_R01.DM01-02】 |
| 仕様 | 登録済みの顧客情報を削除する | 【DAS_R01.DM01-03】 |
| 仕様 | 顧客情報を削除した場合、当該顧客に紐づく製品情報をすべて削除する | 【DAS_R01.DM01-04】 |
