# 【DAS_R03】プラットフォーム管理

## 要求

過去に開発したECUのハードウェア・ソフトウェア資産（プラットフォーム）を登録・変更・削除・一覧表示・検索し、派生管理を行う

### 理由

過去の資産を活用したプロダクトライン開発を実現し、開発コストを削減するため

### 説明

ECUサプライヤは複数のプラットフォームを保持する。
