# 【DAS_R04.DM03】パーミッション設定

## 要求

ユーザーごとにパーミッションを設定する

### 理由

顧客・製品・プラットフォーム・開発プロセスの単位できめ細かなアクセス制御を実現するため

### 説明

記載無し

## 仕様

| 種別 | 内容 | 仕様番号 |
| --- | --- | --- |
| 仕様 | 顧客単位でパーミッションを設定する | 【DAS_R04.DM03-01】 |
| 仕様 | 顧客の製品単位でパーミッションを設定する | 【DAS_R04.DM03-02】 |
| 仕様 | プラットフォーム単位でパーミッションを設定する | 【DAS_R04.DM03-03】 |
| 仕様 | 開発プロセス単位でパーミッションを設定する | 【DAS_R04.DM03-04】 |
| 仕様 | 各単位について、書込可能（作成・変更・削除）または閲覧のみを指定する | 【DAS_R04.DM03-05】 |
