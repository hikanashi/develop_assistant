# 【DAS】AI駆動開発支援システム

## 要求

A-SPICE開発プロセスに沿ったECU開発において、生成AIを活用した要求分析・成果物生成・構成管理・製品窓口対応を一元的に支援するシステムを提供する

### 理由

企業ブランドの価値向上、競合他社との競争力向上のために、開発コスト削減・開発スピード向上を実現するため

### 説明

利用者はECUサプライヤの従業員（システムエンジニア、レビューアー、マネージャー、顧客への営業窓口）であり、ITリテラシーは高くないため、GUIなどグラフィカルかつノーコードで操作できることを前提とする。

## 用語

| 用語 | 説明 |
|---|---|
| ECUサプライヤ | 本システムを導入する先の企業。 |
| ユーザー | ECUサプライヤの社員。利用者に該当する。 |
| 顧客 | 自動車メーカー(OEM)を指す。納品した製品を自動車に組み込む。 |
| 製品 | 顧客に納品する製品。顧客ごとに異なる名称がつく。 |
| プラットフォーム | ECUサプライヤの既存資産。過去に開発したECUのハードウェアやソフトウェアの組み合わせの総称を指す。<br>ECUサプライヤは複数のプラットフォームを持っている。 |
| A-SPICE | Automotive SPICE v4.0を指す。 |
| 開発プロセス | A-SPICEのSYS.1、SYS.2、SWE.1などの個別の活動を指す。またそれらの総称のこと。 |
| 顧客入力物 | 顧客から入力されるインプット資料。顧客ごとにドキュメント構成や形式が異なる。 | 
| 成果物 | A-SPICEに従って複数種類の成果物がある。<br>具体的には開発プロセスの中で作成するドキュメント、モデルファイル、ソースコード等を指す。 |
| リビジョン | 成果物を変更するごとに付与される。 | 
| バージョン | 顧客への製品納入などのマイルストーンに対して付与される。Gitのタグのようなもの。 |
